  (실제 percentile 53 — 카테고리 유탕면 38개 중 20등), 영양성분 실제 per-100g
  (나트륨 **1,360mg** / 당류 **5g** / 단백질 **8g**) + 실제 앱과 동일하게 **"100g당"** 표기 추가.
- 판단(원칙 D: 임의 리디자인 금지): 실제 앱 결과화면은 점수를 "색 박스 + 숫자 + 한글 등급(보통)
  + 순위줄"과 영양성분 목록으로 보여주지만, 웹 히어로의 링/스탯 타일은 웹 고유 디자인 톤이라
  구조는 바꾸지 않고 **데이터·문구만** 정확히 맞췄습니다. 이미지 출처 캡션은 실제 앱엔 있으나
  데모 신라면은 이미지가 없어(placeholder) 웹 아이콘 플레이스홀더가 오히려 정확 → 추가 안 함.

**② 히스토리 (홈 페르소나 데모 폰)**

  유지. 배지 위치·등급 색 체계는 일치.

**③ 셀프 등록 슬롯**

  **"표시사항" → "뒷면"**으로 교체(실제 촬영 단계 "제품 뒷면(영양정보)" 반영).

### 2-2 실제 DB 데이터 교체 (SELECT만 사용)
- 데모 제품명(신라면/새우깡/메로나)은 유지. 정확 SKU가 DB에 없어 가장 가까운 실제 제품의
  실제 점수를 사용:
  - **신라면 → "신라면 큰사발"(114g)** — 플레인 신라면 120g 봉지는 visible products에 없음.
  - **새우깡 → "깐풍새우깡"(80g)** — 플레인 새우깡 180g은 영양정보 null이라 persona_scores 없음.
  - **메로나 → "메로나"(75ml)** — 정확 일치.
- 페르소나별 실제 점수(`persona_scores.final_score` 반올림)로 `site-config.ts`의 `DEMO` 교체.
  personas는 `is_filter_type=false` 7종만(비건 제외).
- 히어로 영양성분: 신라면 큰사발 실제 per-100g (나트륨 1359.6→1,360 / 당류 5.3→5 / 단백질 7.9→8).
- **대체상품 검증**: 웹이 쓰던 "오뚜기 진라면 순한맛"은 **DB에 없음** → 저염식단 기준 신라면(0점)보다
  점수 높은 실제 유탕면으로 교체. **농심 사리면** 선택(같은 농심·유탕면, 나트륨 382 vs 신라면
  1,360/100g로 실제로 훨씬 낮음, 저염식단 50 vs 0, 종합 57 vs 48). 히어로(종합건강관리)엔 57점,
  저염식단 대체블록엔 신라면 **0점** → 사리면 **50점**으로 반영.

### 데이터 주의 (성태님 확인 권장)
- **유탕면 카테고리에 선혜청 전통한과(오복/고향생각/만수무강 등)** 여러 건이 저염식단 100·나트륨
  0으로 섞여 있음 = 카테고리 분류 오류로 보임(한과가 유탕면으로 분류). 대체상품엔 명백한 실제
  라면(농심 사리면)만 써서 회피했으나, **앱 자체의 대체상품 추천 품질에도 영향** 갈 수 있으니
  카테고리 정합성 점검 권장.
- 신라면 저염식단 점수 **0.0**은 실제 값(초고나트륨 → 0 하한). 데모에 그대로 노출.
